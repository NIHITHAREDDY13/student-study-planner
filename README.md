# Student Study Planner

A simple web-based study planner designed to help students organize and manage their study tasks.

## Features

- Add study tasks
- Select a subject for each task
- Set a date for tasks
- Mark tasks as completed
- Tasks are saved using browser Local Storage
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was developed as part of my ApexPlanet internship to practice front-end web development and JavaScript concepts.
